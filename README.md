# PDF to Audio Converter  

## Manipal Institute of Technology (MIT)

---

## Project Overview

This project is developed as an academic mini project to demonstrate the use of
Python for document processing and accessibility.

The application reads the content of a PDF document and converts the extracted
text into an audio file. It is designed to work with both normal text-based PDFs
and complex PDFs such as resumes or scanned documents.

The main objective of this project is to make document content accessible in
audio format and to understand how different technologies can be integrated
together in a single workflow.

---

## Technologies Used

- Python programming language  
- PDF processing techniques  
- Optical Character Recognition (OCR)  
- Text-to-Speech conversion  

(The required tools and libraries are configured during development and are not
hardcoded in the project description.)

---

## Working Principle

The project follows the below logical flow:

1. A PDF file path is provided as input  
2. Each page of the PDF is processed  
3. Text is extracted from the document  
4. The extracted text is converted into speech  
5. An audio file is generated as output  

---

## How to Run the Project

1. Clone or download the repository  
2. Open the project folder in a Python-supported environment  
3. Run the main Python file  
4. When prompted, provide the path of the PDF file  
5. After execution, the audio output file will be generated in the project folder  

---

## Applications

- Audio support for documents  
- Accessibility for visually impaired users  
- Learning and revision using audio content  
- Understanding integration of OCR and speech synthesis  

---

## Conclusion

This project demonstrates how Python can be used to build a practical application
by integrating document processing and audio generation. It provides hands-on
experience with real-world tools and improves understanding of file handling,
text extraction, and speech synthesis.
